## Using XcodeGen

### Regenerate Project

If you need to regenerate the project file (after modifying `project.yml`):

```bash
cd PediLens
xcodegen generate
```

### Modify Project Structure

Edit `project.yml` to:
- Add new source files/folders
- Add frameworks
- Change build settings
- Add build scripts
- Configure schemes

Then run `xcodegen generate` to update the project.

### Benefits of XcodeGen

- ✅ **Version Control Friendly**: `project.yml` is human-readable YAML
- ✅ **Merge Conflicts**: Easier to resolve than `.pbxproj` conflicts
- ✅ **Reproducible**: Anyone can regenerate the exact same project
- ✅ **Automation**: Can be integrated into CI/CD pipelines
- ✅ **Documentation**: `project.yml` documents project structure

## Troubleshooting

### Issue: "xcodegen: command not found"

**Solution**: Install XcodeGen
```bash
brew install xcodegen
```

### Issue: Build fails with missing files

**Solution**: Ensure all source files exist in the correct locations
```bash
# Check file structure
ls -R PediLens/
```

### Issue: Signing errors

**Solution**: Configure signing in Xcode
1. Open project in Xcode
2. Select target → Signing & Capabilities
3. Select your development team
4. Enable "Automatically manage signing"

### Issue: Simulator not found

**Solution**: List available simulators
```bash
xcrun simctl list devices
```

Use an available simulator name in build commands.
