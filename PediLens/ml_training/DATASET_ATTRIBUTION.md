# Dataset Attribution and Acknowledgments

## Primary Training Dataset

### Wound Segmentation Images

**Creator:** leoscode  
**Platform:** Kaggle  
**URL:** https://www.kaggle.com/datasets/leoscode/wound-segmentation-images  
**Description:** 2,760 wound images with segmentation masks  
**Size:** 697 MB  
**Last Updated:** February 2024  

**License:** Please check the Kaggle dataset page for current license terms and conditions.

**Citation:**
```
leoscode. (2024). Wound images segmentation [2760 samples]. 
Kaggle. https://www.kaggle.com/datasets/leoscode/wound-segmentation-images
```

**Usage in PediLens:**
This dataset is used as the default training data for the wound boundary detection model. The trained model is deployed in the PediLens iOS application for on-device wound segmentation.

## Attribution Requirements

If you use models trained on these datasets, please:

### For Research Publications
1. Cite the original dataset(s) used for training
2. Include the Kaggle URL in your references
3. Acknowledge the dataset creators by name
4. Review and comply with the dataset's license terms

### For Commercial Use
1. Review the license terms on each dataset's Kaggle page
2. Ensure compliance with any commercial use restrictions
3. Provide appropriate attribution as required by the license
4. Consider reaching out to dataset creators for permissions

### For Open Source Projects
1. Include this attribution file in your repository
2. Link to the original datasets in your README
3. Acknowledge dataset creators in your documentation
4. Comply with dataset license terms

## License Compliance

### Important Notes

1. **Check Current License:** Dataset licenses may change. Always check the Kaggle page for the most current license terms before using the data.

2. **Commercial Use:** Some datasets may have restrictions on commercial use. Review license terms carefully if deploying in a commercial product.

3. **Data Privacy:** Ensure all training data is properly de-identified and complies with relevant privacy regulations (HIPAA, GDPR, etc.).

4. **Model Derivatives:** Trained models may be subject to the same license terms as the training data. Consult with legal counsel if uncertain.

## Contributing Your Own Data

If you collect your own wound images for training:

1. **Obtain Proper Consent:** Ensure patients provide informed consent for image use
2. **De-identify Data:** Remove all personally identifiable information
3. **Document Provenance:** Keep records of data collection methods
4. **Consider Sharing:** If appropriate, consider contributing to open datasets
5. **Comply with Regulations:** Follow HIPAA, GDPR, and other relevant regulations
